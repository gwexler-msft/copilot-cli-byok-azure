**Download and review, then merge deliberately; none of these files installs itself.** Keep a protected backup of the previous configuration outside source control. Do not overwrite personal settings, clear organizational denies or move environment/policy keys into a user/workspace JSON. Check effective profile, remote, repository, environment and policy overrides after merging.

| File | Destination and purpose |
| --- | --- |
| [CLI user settings](cli-settings.json) | Merge into the approved profile's `$COPILOT_HOME\settings.json` (normally `%USERPROFILE%\.copilot\settings.json`), not old `config.json` or the narrower repository subset. Manual/interactive, hooks off, no pretrusted folders/URLs, local data stance and staged downloads. |
| [VS Code user/profile settings](vscode-settings.json) | Merge window controls into the intended **Local** profile. Put application/application-machine controls in the supported default-profile/application settings, not `.vscode\settings.json`; review remote overrides. Includes pre-Collector OTel **off**, capture off, telemetry and feedback off, opt-in execution, Claude/Codex agent hosts off and automatic updates off (`update.mode="none"`, extension auto-update off). |
| [Shared managed policy](managed-settings.json) | Admin-reviewed nested JSON for `%ProgramFiles%\GitHubCopilot\managed-settings.json`; protect file ACLs and merge with existing policy. It sets `permissions.disableBypassPermissionsMode="disable"`, denies `Read(~/.ssh/**)`, asks before `Shell(git push *)`, empties the `allowedMcpServers` and `strictKnownMarketplaces` allowlists, disables `remoteControl` and turns telemetry and content capture off with capture locked. It is a starting baseline, not a complete enterprise policy. |
| [Azure CLI environment fragment](Set-CliProviderEnvironment.ps1) | PowerShell 7.2+, current-process environment only. Requires gateway host, base model and deployment inputs, and an approved launcher that has already set `COPILOT_PROVIDER_API_KEY_COMMAND` to the Entra ID/Okta JWT token helper; configures an `azure` Responses route at `https://<GatewayHost>/openai`. Stops without printing values if a stored API key, bearer token, GitHub token or other conflicting variable is present. Does not log in, launch a client, provision a model, change stored settings or configure telemetry. |

The managed JSON is not a VS Code user-settings file or a registry import. Native MDM uses documented dotted `REG_SZ` values, whereas the shared file uses nested objects. For Local VS Code, enforce applicable native policies such as `ChatToolsAutoApprove=false`, `ChatToolsTerminalEnableAutoApprove=false`, `ChatMCP="none"` and, unless an exception is approved, `ChatHooks=false`. Shared Copilot policy takes precedence where the same control is mapped; exact Local/Agent Host support is not interchangeable.
